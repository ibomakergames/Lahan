# لَحْن (LAHN)

تطبيق Android أصلي بواجهة عربية واتجاه RTL، وتصميم داكن بالأسود والفضي والرمادي.

## الإصدار الحالي: 0.9.1

- البحث عن الأغاني والفنانين عبر iTunes Search API.
- تشغيل المعاينات الصوتية داخل التطبيق.
- حفظ المقاطع في مكتبة محلية دائمة.
- تنزيل روابط المعاينات المتاحة إلى مجلد Music/LAHN باستخدام DownloadManager.
- عرض حالة تنزيلات لَحْن وتحديث القائمة.
- بناء APK تجريبي تلقائياً عبر GitHub Actions.

## الحصول على APK

افتح تبويب Actions في المستودع، واختر أحدث تشغيل ناجح لسير عمل Android APK، ثم نزّل artifact باسم LAHN-debug-apk.

## ملاحظات مهمة

- خدمة iTunes تعرض معاينات قصيرة وليست مكتبة أغنيات كاملة.
- التنزيل الحالي يحفظ رابط المعاينة المتاح فقط بصيغة M4A.
- لا يتجاوز التطبيق حماية المنصات أو قيود حقوق النشر.
- التشغيل بالخلفية مع إشعار تحكم وشاشة قفل، وتنزيل الفيديو، ما زالت ميزات غير مكتملة.
- إصدار Debug مخصص للاختبار؛ يلزم اختبار التطبيق على أجهزة فعلية قبل نشر إصدار نهائي.
