# لَحْن (LAHN)

تطبيق Android أصلي للبحث عن معاينات الموسيقى وتشغيلها وحفظها، بواجهة عربية RTL وألوان أحادية: الأسود والرمادي والفضي.

## الإصدار 0.2.0

- واجهة عربية داكنة مع تبويبات الرئيسية والبحث والتنزيلات والمكتبة.
- البحث عن المقاطع عبر iTunes Search API.
- تشغيل المعاينات الصوتية داخل التطبيق باستخدام AndroidX Media3.
- تنزيل المعاينات المتاحة إلى Music/LAHN عبر Android DownloadManager مع إشعار النظام.
- مكتبة محلية دائمة تحفظ المقاطع المختارة حتى بعد إغلاق التطبيق.
- صفحة تنزيلات تعرض حالة الملفات التي يديرها DownloadManager مع إمكانية تحديث القائمة.
- بناء APK تجريبي تلقائياً عبر GitHub Actions عند كل تحديث للمستودع.

## البناء

يتطلب Android Studio أو بيئة بناء Android مع JDK 17 وAndroid SDK Platform 35. يمكن تنزيل APK التجريبي من تبويب Actions بعد نجاح مهمة Android APK.

## حدود النسخة الحالية

- iTunes يوفر معاينات قصيرة فقط؛ حفظ المقطع في المكتبة لا يحوّله إلى أغنية كاملة.
- التنزيل الحالي ينزّل رابط المعاينة المتاح فقط بصيغة M4A.
- لا يتجاوز التطبيق أنظمة الحماية أو قيود منصات الموسيقى والفيديو.
- المشغل الخلفي المستمر والتحكم من شاشة القفل وتجربة تنزيل الفيديو ليست مكتملة بعد.
- يجب تثبيت التطبيق واختباره على جهاز Android فعلي قبل اعتباره إصداراً نهائياً.
