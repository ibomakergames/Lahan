# لَحْن (LAHN)

تطبيق Android للاستماع إلى معاينات الموسيقى والبحث عنها، بواجهة عربية RTL وألوان أحادية (أسود، رمادي، فضي).

## الحالة الحالية — 0.1.0

هذه هي القاعدة الأولى للمشروع، وليست إصداراً نهائياً أو APK جاهزاً.

- مشروع Android أصلي باستخدام Kotlin وJetpack Compose.
- واجهة داكنة عربية مع تبويبات رئيسية.
- البحث عن المقاطع عبر iTunes Search API.
- تشغيل معاينات الصوت داخل التطبيق باستخدام AndroidX Media3.
- تنزيل المعاينة الصوتية إلى مجلد Music/LAHN عبر DownloadManager.

## فتح المشروع

1. افتح Android Studio.
2. اختر **Open** وحدد مجلد المستودع.
3. استخدم JDK 17 وثبّت Android SDK Platform 35.
4. نفّذ Gradle Sync ثم شغّل التطبيق على جهاز Android.

## ملاحظات

- البحث يعرض معاينات قصيرة متاحة من iTunes، وليس مكتبة الأغاني الكاملة.
- التنزيل الحالي يحفظ ملف المعاينة المتاح فقط بصيغة M4A؛ لا يعني ذلك تنزيل الأغنية الكاملة.
- لم يُنشأ APK ولم يُجرَ اختبار على هاتف فعلي بعد.
- ميزات الخلفية والإشعارات والتحكم من شاشة القفل، وقائمة التنزيلات والمكتبة الدائمة، ما زالت ضمن مراحل التطوير التالية.
